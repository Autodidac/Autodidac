- AI-assisted inspection, testing, and improvement
- Reviewed development output for future training data

- Specialized local models for editor and runtime tasks
- External MCP helpers for planning, coding, review, assets, and automation
- External model feedback to improve local workflows
- Build, run, capture, verify, diagnose, and iterate

## AI Self-Iteration Direction

**Epoch already builds and tests candidate versions of itself.** In the Development edition, AI-assisted source changes go into a separate candidate. Epoch compiles it, runs verification, and brings the results back for human review.

- AI-assisted coding
- AI-assisted refactoring
- AI-assisted debugging
- Engine-aware task execution
- Automated builds and verification for candidate engine versions
- Runtime launch and capture validation
- Checks based on screenshots, logs, and artifacts
- Reviewed training examples from real engine use
- Local AI model integration
- Embedded models in generated projects as a development goal
- Specialized local models for editor and runtime tasks
- External model support for planning and review
- MCP tools, models, and automation workers
- Human review before promoting successful fixes and workflows
- AI controls integrated into the editor
- Internal coding, upgrades, tests, and verification in one loop

## Why Epoch Is Different

Unreal, Unity, and Godot are proven engines with established asset pipelines and largely human-driven iteration. Their workflows typically organize these pieces separately:

- Engine
- Editor
- Runtime
- Scripting
- Plugins
- Build tools
- External automation
- External AI assistants

Epoch brings them into one development workflow:

- Engine, editor, and runtime
- Game and software project support
- Internal AI development loop
- Embedded local model support as a development goal
- Specialized local helper models
- MCP-connected external helpers
- AI-assisted development
- Automated verification
- Cooperation between local and external models
- Runtime captures and diagnostics
- C++23 scripting compiled with the engine or project
- Generated project shells
- Tools that inspect and improve the engine they belong to
